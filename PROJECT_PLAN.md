# Intelligent Object Detection Using Deep Learning

## Project Information

- **Project Title:** Design and Development of Intelligent Object Detection using Deep Learning
- **Team Name:** TrickedTriad
- **Team Members:** Nitya Jain, Shubhi Agrahari, Sonali Chauhan
- **Guide:** Dr. Vivek Sharma
- **Technology:** Python, YOLO11n, OpenCV

## Project Vision

Develop an intelligent system that detects and identifies objects in images, videos, and live camera streams. The system will display object names, bounding boxes, confidence scores, tracking IDs, and object counts.

## Practical Application

The system will be explored as a prototype for smart campus monitoring, including people and vehicle monitoring, entry/exit counting, and restricted-area alerts.

## Mathematics and Computing Connection

- Image representation using arrays and matrices.
- Bounding-box coordinates using coordinate geometry.
- Confidence scores from model predictions.
- Statistics for object counting and activity analysis.
- Time-series analysis for monitoring activity over time.
- Algorithms for object detection and tracking.

## Development Approach

Complete all five project milestones:

1. Requirement Analysis
2. System Design and Methodology
3. Implementation
4. Testing and Validation
5. Deployment

Existing experiments and files will be preserved while the application is developed incrementally.




## Project Objectives

1. To develop an intelligent object detection system using YOLO11n.
2. To detect and identify objects in images, videos, and live camera streams.
3. To display object names, bounding boxes, and confidence scores.
4. To implement object tracking and class-wise counting.
5. To evaluate system performance using detection results and FPS.
6. To explore the system's application in smart campus monitoring.





## Functional Requirements

1. The system shall accept images and videos as input.
2. The system shall use OpenCV to read and process visual data.
3. The system shall load a pre-trained YOLO object detection model.
4. The system shall detect and identify supported objects.
5. The system shall determine object locations using bounding boxes.
6. The system shall provide confidence scores for detected objects.
7. The system shall display results with labels and bounding boxes.
8. The system should support saving processed output, subject to implementation feasibility.
9. The system shall provide appropriate feedback for invalid or unsupported input.
